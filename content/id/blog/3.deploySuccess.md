Sekarang pukul 22:12. Proses deployment akhirnya selesai.

Saya mulai beberapa jam yang lalu, tetapi saya sudah lama tidak mengelola VPS, jadi saya lupa banyak hal tentang cara melakukan deployment.

Awalnya, Gemini mengajari saya caranya, tetapi akhirnya saya mencari informasi di Stack Overflow dan situs lain. Terutama tentang kesalahan yang muncul.

VPS memiliki RAM terbatas, jadi saya tidak bisa melakukan build di server. Saya pernah mendengar bahwa saya bisa melakukan build di GitHub, jadi saya meminta Gemini lagi untuk memberikan petunjuk tentang cara melakukannya.

Percobaan pertama gagal, dan saya harus mengutak-atiknya sekitar tiga kali sampai stabil.

Saya menulis artikel ini sambil mendengarkan siaran langsung turnamen Rocket League dari sebuah kantor sebagai musik latar.

Mulai besok, saya akan mencoba menulis satu artikel per hari. Saya sudah menundanya sejak lama.
